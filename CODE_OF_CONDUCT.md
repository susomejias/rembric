# Code of Conduct

This project has adopted the **Contributor Covenant**, version 2.1, by
reference. The canonical text is published at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt>

By participating in this project — opening issues, submitting pull requests,
commenting, reviewing, or any other form of contribution — you agree to abide
by its terms.

## Scope

This Code of Conduct applies within all project spaces (the repository, issue
tracker, discussions, pull requests, the project's MCP / API surfaces when used
to interact with the maintainers, and any space where someone is representing
the project) and to all participants.

## Enforcement contact

Reports of conduct concerns may be sent to the maintainer at
**jesusmejias.jm@gmail.com** with the subject line
`[rembric-coc] <short description>`.

- Reports are confidential.
- The maintainer acknowledges receipt within **5 business days**.
- Consequences follow the Community Impact Guidelines published at the
  Contributor Covenant URL above (Correction → Warning → Temporary Ban →
  Permanent Ban, scaled to severity).
- A report does not need to include the reporter's real identity; pseudonymous
  reports are accepted.

The maintainer SHALL recuse themselves from enforcement decisions in any case
where they are personally involved; in such cases the report is escalated to a
mutually agreed neutral party.
