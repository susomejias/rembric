## REMOVED Requirements

### Requirement: The session detail view MUST list the summary version history, capped

**Reason**: The requirement is conditional on the table it renders, and says so in its own first paragraph — _"Without a reader the table is storage nobody consumes; with one, a summary displaced by a later curated write is recoverable by an operator reading it and handing it back."_ `session_summary_versions` is retired (`sessions`), so there is nothing to read and no operator recovery to offer. Keeping the section would render an empty block on every session detail page forever, which is worse than removing it: an unconditionally-empty history reads as a broken feature rather than an absent one, and the requirement's own empty-state clause exists precisely to keep "no versions yet" distinguishable from "feature missing" — a distinction that has no meaning once the table cannot ever hold a row.

The operator does lose a real capability, and this is not a no-op removal: reading text a curated write displaced and handing it back was the only operator-facing recovery path the product had. That loss is the accepted risk of retiring the table, recorded in `sessions`, "A session summary MUST follow the documented structure". It is NOT replaced by a weaker dashboard surface, because after "A curated session-summary write MUST be merged section-wise with the stored summary" the common displacement no longer happens and the remaining one leaves nothing to display.

**Migration**: `/dashboard/sessions/:id` renders the `Summary` block and goes straight to `Memories (N)`. `SUMMARY_HISTORY_MAX`, the two `admin*` reads that fed the section, its template block and its dedicated CSS rules are removed, along with the whole `apps/server/src/dashboard/session-summary-history.test.ts` file. No route, form, action or confirmation modal is involved — the section never had one, which is what makes this removal purely subtractive. The published session-detail-page scenario in "A dashboard user opens a session detail page" is unaffected: it enumerates the metadata, the summary, the memories table and the prompts table, and never named this section.
