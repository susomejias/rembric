# Tasks — retire the global scope

Read `design.md` first: **D1–D22** are cited by number below. Closes issue **#299**.

**Invariants crossed, so read these before touching anything.** Append-only memory is crossed **narrowly and with a spec amendment** (D13, `memory` delta): the migration `UPDATE`s `memory.project_id`; `content` and `title` stay immutable and no runtime path may rewrite `project_id`. Scope-at-the-service-layer is **strengthened**, not weakened. One new migration file under `db/migrations/`; no SQL enters services, dashboard, MCP or server. No new MCP tool — two input properties and one error code are REMOVED. No dashboard design token changes.

**Order matters.** §1 (migration) before §2–§4 (its tests). §5 (the two return statements) before §6–§8, because every retargeting downstream depends on the resolver. §9 (truthfulness) last among the code sections, so it sweeps a settled surface.
