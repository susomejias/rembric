Read `design.md` first: **D1–D22** are cited by number below. Closes issue **#299**.

**Invariants crossed, so read these before touching anything.** Append-only memory is crossed **narrowly and with a spec amendment** (D13, `memory` delta): the migration `UPDATE`s `memory.project_id`; `content` and `title` stay immutable and no runtime path may rewrite `project_id`. **Order matters.** §1 (migration) before §2–§4 (its tests). §5 (the two return statements) before §6–§8, because every retargeting downstream depends on the resolver. §9 (truthfulness) last among the code sections, so it sweeps a settled surface.
