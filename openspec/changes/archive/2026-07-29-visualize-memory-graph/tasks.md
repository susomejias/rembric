# Tasks — Phase 1 shipped, Phase 2 withdrawn and removed

> **This file was rewritten when the graph view was withdrawn.** The renderer work plan is gone, because a task list is a work plan and there is no longer work behind it — the _evidence_ (four measured engines, the trilemma, the read-path measurements, the traps) lives in `design.md`, which is where a rejection record belongs. Sections 1 and 2 below describe what ships. Section 3 is the removal, and it is the work of the withdrawal session.
>
> **Every measurement quoted anywhere in this change was taken in a container with no GPU** — WebGL runs through SwiftShader — so any frame-rate figure is a worst case no operator has. Settle times are CPU-bound and more transferable, but they too are this container's.
