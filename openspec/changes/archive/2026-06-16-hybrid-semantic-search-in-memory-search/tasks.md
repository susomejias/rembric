- [x] 4.4 Add a search-specific FTS sanitizer (NOT `escapeFts`, whose `/[^a-z0-9]+/` split truncates `"Botín" → "bot"` (an exact quoted term matching nothing) and drops entirely-non-ASCII tokens): keep WHOLE Unicode word tokens (do not split at non-ASCII chars, do not drop non-ASCII tokens), strip FTS5 metacharacters, balance quotes, and neutralize bareword operators `AND`/`OR`/`NOT`/`NEAR` and leading `*`/`+` (quoting each surviving token as a phrase covers metacharacters + barewords at once).
