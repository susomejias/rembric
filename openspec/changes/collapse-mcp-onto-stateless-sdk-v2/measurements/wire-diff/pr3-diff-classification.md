## Differences not literally named by a row

- **048** — a 2025-era request sent without any prior `initialize` is served instead of refused with `400 Server not initialized`. Row 8 lists the minted id, `404/-32001`, `DELETE` and `GET`; the "server not initialized" refusal belongs to the same session machinery (a sessionful transport remembers whether _this_ session initialized) and disappears with it under decision D1: the SDK's stateless posture answers every 2025 request with a fresh, implicitly initialized server. It is not separately avoidable without reintroducing per-connection state. Reported to the owner as a consequence of D1, mapped to row 8.
- **066–068** — modern-era service is the purpose of the change, not a loss, so it maps to no row of the "What is lost" table.

No other difference was reported: OAuth shapes (071–101), the body cap, the DNS-rebinding gates and every refusal before the handler (054–063, 065, 069, 070) are `same`.
