# stale pending drain — cost, rules v2 (stored links + re-extraction, retired endpoints drained)
CAVEAT: vectors are deterministic pseudo-random unit vectors, NOT embeddings — no retrieval-quality, ranking, fusion or abstention claim may be drawn from this corpus (use `pnpm run eval`). The vocabulary is tiny, so lexical overlap is high and the keep/drain mix says nothing about correctness: this file measures cost only.
model inference: excluded by construction — the drain only reads vectors already in memory_vec (fixture-drain no-embedder phase proves it) and no embedder is loaded in this process.
corpus: pnpm run corpus:build generator (buildCorpus, seed 1) with --relations R; it writes R relations between random pairs of one scope slot (i % 6), 25% left pending, 5% orphaned, 70% judged. The drain is measured on scope vol-shared.
settings: createDb defaults (WAL, synchronous NORMAL, 64 MB page cache, 256 MB mmap); every measurement runs on a copy-on-write clone of the built database, so each series starts from the same state.
